# Security policy

Do not post real card statements, account numbers, personal identifiers or API keys in public issues. Report suspected vulnerabilities privately to **support@credonomics.in** and include a synthetic minimal reproduction. The engine does not make network calls. Consumers are responsible for securing transaction inputs, storage and any interfaces they build on top.

No claim of certified compliance or banking integration is made. Maintainers review reports as capacity permits; no bounty or SLA is implied.
