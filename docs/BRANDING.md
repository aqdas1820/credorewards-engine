# CredoRewards brand identity

CredoRewards is a product identity of **[CredoNomics Investment Solutions](https://credonomics.in)**.
This repository presents the product as part of the same company family as
[CredoNomics Cyber Solutions](https://github.com/aqdas1820/credonomics-cyber-solutions).

## Owner-supplied artwork

The two README assets were prepared from the product artwork supplied by
the repository owner in November 2026. They are intentionally stored in this
repository so the GitHub README does not rely on external image hosting.

| Asset | Usage |
| --- | --- |
| [CredoRewards banner](public/credorewards-brand-banner.webp) | Centered primary README hero, including the original parent logo, gift artwork and CredoRewards wordmark |
| [A CredoNomics Product badge](public/credonomics-parent-product-badge.webp) | Smaller parent-company signature featuring the original arrow-and-growth-bars logo |

The supplied image was a screenshot. These README-specific WebP assets use
cropped portions of that image, excluding surrounding app controls and caption.
The colors, symbols, wordmark and labels were **not redrawn or replaced**. The
original vector design files were not supplied, so these raster assets should
**not** be represented as scalable design masters or used for print.

The larger banner includes the words *Rewards & Loyalty Platform*, *Earn*,
*Engage* and *Redeem* as **branding**. They do not assert that this alpha SDK
currently provides loyalty accounts, points-redemption services, merchant
programs, or live payment integrations. For implemented features, refer to the
[README](../README.md) and [production-readiness status](PRODUCTION-READINESS.md).

## Presentation principles

- Use the real product artwork—not an unrelated generic credit-card icon.
- Keep the parent company's name and original arrow/growth-bars mark intact.
- Follow the parent company's teal/cyan plus violet/indigo identity in badges
  and documentation accents without altering the underlying SDK.
- Preserve visible distinction between this **experimental alpha SDK** and
  the commercial/product ambitions described by the banner.
- Include meaningful alt text and an accessible text product description.
- Avoid issuer logos, third-party bank endorsements, fabricated screenshots,
  unverifiable customer counts or claims of production compliance.
