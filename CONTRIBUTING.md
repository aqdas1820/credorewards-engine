# Contributing

Please open an issue describing the financial calculation or bug and include a **fictional** example and the expected result. Tests should use integer paise and deterministic transaction identifiers. Avoid issuer-specific facts without first-party public citations and effective dates. To run checks: `npm install && npm test && npm run typecheck`.

For contributions, keep PRs small, document reward rule semantics and retain source attribution. All source contributions are under MIT unless clearly stated otherwise.
